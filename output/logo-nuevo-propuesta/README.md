# Logo nuevo — propuesta

Propuesta geométrica compacta guardada para futura revisión. La web utiliza el logo original `src/Images/logo.png`.

- `logo-nuevo-propuesta.png`: logo completo, fondo transparente, 1404 × 336 píxeles.
- `simbolo-nuevo-propuesta.png`: símbolo, fondo transparente, 560 × 560 píxeles.
- Archivos `.svg`: originales vectoriales editables.

Esta es la primera versión del símbolo nuevo, recuperada después de descartar la variante con S. Paleta: verde #42634A y tinta #18231C. Los SVG conservan texto editable con Helvetica/Arial como familia tipográfica; los PNG mantienen la apariencia exportada.
